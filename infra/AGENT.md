# infra — 로컬 실행·서비스 연결·배포 환경 범위

기준: [루트 설계](../AGENT.md) 2·6·10·13장.

## 역할과 구현 대상

Docker Compose와 서비스별 Dockerfile, 내부 네트워크·포트·환경 변수·영속 볼륨·기동 순서·헬스체크를 구성한다. 기능 로직은 각 서비스가 소유한다.

| 실행 단위 | 주요 기술·연결 |
|---|---|
| web | Vue/Vite 빌드·웹 제공, Gateway 연결 |
| gateway | Python/FastAPI, DB·Agent·RabbitMQ |
| agent | Python/LangGraph, 모델 API·MCP 2개·체크포인트 |
| business-mcp | Python/FastMCP, 내부 9101 /mcp, Gateway 내부 API |
| rag-mcp | Python/FastMCP, 내부 9102 /mcp, Gateway·검색 DB·임베딩 |
| report-worker | Python, RabbitMQ·스냅샷 DB·모델 API |
| postgres | PostgreSQL·pgvector·서비스별 역할·영속 데이터 |
| rabbitmq | 영속 큐·재시도·DLQ·접근 자격 |

## 구현 책임

- 브라우저에 필요한 웹·Gateway만 노출하고 Agent·MCP·DB·큐는 내부 네트워크로 제한한다. 로컬 디버그 공개는 별도 설정으로 구분한다.
- DB·큐 준비 여부를 확인하고 앱도 재연결·준비 실패를 처리하게 한다. 단순 기동 순서만 신뢰하지 않는다.
- 마이그레이션 적용·권한 설정과 서비스 기동 절차를 분리해 재현 가능하게 한다.
- DB·큐·체크포인트를 영속화하고 재시작 후 데이터·작업이 유지되도록 구성한다.
- RabbitMQ 영속 작업·전달 확인·소비 ACK·재시도·DLQ 설정을 생산자/워커 계약과 맞춘다. 재시도 폭주·무한 루프를 막는다.
- 모델·DB·서비스 인증 키는 환경/비밀 설정에서 주입한다. 추후 .env.example에는 이름·빈 예시만 두고 실제 키를 커밋하지 않는다.
- 개발·테스트·일반 실행을 구분한다. fixture·가상 시계·임시 사건 API는 일반 환경에서 비활성화한다.
- 기본 모델 제한, MCP 주소, 재시도 상한, 로그·추적·시간 제한을 서비스 설정과 일치시킨다.
- CPU·메모리·임베딩 런타임 요구와 이미지·SDK·프로토콜 고정 버전을 문서화한다. 불필요한 새 인프라를 추가하지 않는다.

## 연결·범위 밖

DB 스키마·역할 정의는 migrations, 사건·큐 payload는 contracts, 서비스의 멱등성·권한·복구는 각 서버가 구현한다. 이곳에서 시나리오를 발행하거나 권한 검사를 프록시 설정만으로 대체하지 않는다.

## 완료 기준

새 개발 환경에서 문서 절차로 기동·마이그레이션·헬스 확인이 가능하다. 내부 MCP 연결·DB·큐가 실제 서비스와 연결되고, 재시작 후 데이터·작업·체크포인트가 유지된다. 테스트 데이터와 운영 실행을 분리하며 중지·재시작·재빌드·데이터 보존 방법을 docs와 함께 제공한다. 검증 전 이미지 빌드·배포 성공을 주장하지 않는다.
