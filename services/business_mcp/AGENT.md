# business-mcp — 업무 도구 서버 구현 범위

기준: [루트 설계](../../AGENT.md) 6.1~6.3·6.5장, [서비스 공통](../AGENT.md).

## 역할과 기술

Python·MCP SDK(FastMCP), Streamable HTTP `/mcp`, 기본 내부 포트 9101. Agent가 실제 발견·호출하는 업무 조회·변경 도구를 제공한다. Gateway 내부 API의 어댑터이며 DB에 직접 접근하지 않는다.

## 구현할 도구

| 도구 | 기능 | 허용 범위 |
|---|---|---|
| `get_session_context` | 공개 과제·단계·시간·업무 버전 | 동료·팀장, 미래 사건·리포트 제외 |
| `list_tasks` | 태스크·담당·상태·revision 조회 | 동료·팀장 |
| `get_document_section` | 과제 문서 항목 조회 | 해당 세션의 동료 |
| `propose_task_assignment` | 분업 제안 저장 | 동료, 바로 확정하지 않음 |
| `apply_task_assignment` | 수락 또는 조정 종료 정책에 따라 확정 | 진행자 코드 전용 |
| `update_task_status` | 동료의 담당 태스크 상태 변경 | 자기 담당만 |
| `publish_colleague_draft` | 담당 영역 초안 공유 | 사건·담당·revision 허용 범위 |
| `record_observation` | 검증된 규칙 결과·근거 저장 | 규칙 실행기 전용, 일반 모델 제외 |

## 구현 책임

- 설명·inputSchema·outputSchema·조회/변경 특성을 정의하고 실제 tools/list·tools/call에 등록한다.
- `gateway_client.py`로 내부 조회·변경을 요청하고 업무 오류를 MCP 오류 계약으로 변환한다.
- 검증 가능한 기업·세션·역할·scope·만료를 검사한다. MCP 세션 ID나 모델 인자를 권한 근거로 쓰지 않는다.
- Gateway를 호출할 때 수신 서비스용 자격을 사용한다. 브라우저 토큰을 그대로 전달하지 않는다.
- 변경에는 같은 `command_id`와 `expected_revision`을 전달하고 Gateway가 최종 검증·중복 방지를 수행한다.
- 도구 등록 필터와 서버 인가를 함께 적용한다. 어시스턴트에 변경 도구를 제공하지 않는다.
- 타임아웃·권한·없는 ID·상태/버전 충돌을 구분하고 입력·출력 크기와 호출 시간을 제한한다.

## 계약과 오류

[contracts](../../contracts/AGENT.md)의 도구 인자·결과·오류를 단일 기준으로 사용한다. 성공은 structuredContent와 호환 텍스트로, 업무 실패는 isError와 코드·재시도 여부로 반환한다. 프로토콜 오류는 별도로 처리한다.

권한 거절·잘못된 ID·종료 세션·revision 충돌을 무조건 재시도하지 않는다. 변경 응답이 유실돼도 새 멱등 키로 변경을 반복하지 않는다. 원본 서버 예외·키·개인정보를 반환하지 않는다.

## 맡지 않는 범위

DB 모델·SQL, 사용자 로그인, 세션 시계, Graph·모델 호출, 검색·임베딩, 관찰 기준 결정, 리포트 생성. 사용자 화면의 일반 문서 저장을 모두 이 도구로 우회시키지 않는다.

## 완료 기준

- Agent에서 실제 연결·도구 조회·업무 조회·변경이 가능하고 화면·DB에 변경이 반영된다.
- 타 기업·세션·역할 요청과 어시스턴트 변경 요청을 거절한다.
- 중복 명령은 한 번만 반영되고 버전 충돌·종료·타임아웃 오류가 계약과 일치한다.
- 평가 시 도구 실행 입력·결과·Gateway 변경과의 연결 증거를 제시할 수 있다.
