# agent — Graph·Harness·MCP Client 구현 범위

기준: [루트 설계](../../AGENT.md) 5·6·10장, [서비스 공통](../AGENT.md).

## 역할과 기술

Python·LangGraph로 동료·팀장·어시스턴트와 문서 관리 실행을 구성한다. MCP Host와 서버별 Client를 구현하고 `gpt-4o-mini`를 호출한다. 사용자 응시 시간과 업무 DB의 주인은 Gateway다.

## 구현할 기능

- `graphs/`: 진행자 라우팅, 분업 합의 분기·최대 3회 조정, 작업·사건 처리·대기·종료, 페르소나별 모델/도구 루프.
- `state/`: 세션·시나리오 버전, phase·revision, 입력 순서, 협상 횟수, 분업안, 사건·문서·메시지 참조, 보류 작업.
- `checkpoints/`: 영속 저장·복구. 어시스턴트와 동료/팀장, 문서 관리 실행의 thread·메모리를 분리한다.
- `scenario_loader/`: 계약에 맞는 버전 설정을 로드하고 역할 지침·공개 자료 참조를 조립한다. 빈 사건·최소 지침 개발 모드 지원.
- `mcp_clients/`: 두 서버 초기화·기능 협상·tools/list·tools/call, 역할별 도구 바인딩, 결과 검증·타임아웃·재연결.
- `providers/`: 모델 호출·진행 출력·사용량 기록. 모델 자격은 서버 환경에서만 읽는다.
- `prompts/`: 공통 역할·인용·금지 출력 지침. 회사명·구체 사건·지원 역량 매핑을 하드코딩하지 않는다.
- `harness/`: Instructions, Tools, Context, State/Memory, Agent Loop, Guardrails, Recovery, Observability의 실행 적용.

## 도구·역할 경계

- 동료: 업무 조회·분업 제안·자기 담당 태스크 변경·허용 초안 공유·공개 자료 검색.
- 팀장: 공개 업무 맥락·자료와 현재 공지 지시. 임의로 사건 시점·평가 결과를 만들지 않는다.
- 어시스턴트: 공개 자료 검색과 질문·요약·초안 응답. 문서·태스크 쓰기 도구와 숨겨진 사건·관찰 규칙 제외.
- 진행자 코드만 `apply_task_assignment`를, 규칙 실행기만 `record_observation`을 사용할 수 있다. 일반 모델 도구 목록에는 넣지 않는다.
- `모델 판단 → 도구 실행 → 결과 확인 → 다시 판단/응답`을 실제 구현한다. 도구가 불필요하면 직접 응답한다.
- 페르소나 응답당 도구 호출 최대 3회, 모델 실패 재시도 2회. 근거가 없으면 확인되지 않았다고 안내한다.
- 서버가 발급한 기업·세션·역할 범위를 MCP 호출에 묶고 모델이 임의로 덮어쓰지 못하게 한다.

## 문서 승인 Graph

관리자 요청 → rag-mcp 준비 도구 → 변경 요약 → interrupt·체크포인트 → Gateway가 검증한 승인/거절 → 승인 시 인덱싱, 거절 시 취소.

승인 해시 변경·자격 부족을 확인하고 일반 응시 Graph와 독립적으로 재개한다. 모델이 승인 결정을 생성해 인덱싱을 우회하지 못하게 한다.

## 연결·관측

Gateway로부터 저장된 입력·검증된 컨텍스트를 받고 응답·공개 가능한 처리 상태를 반환한다. 업무 도구는 business-mcp를 통해 실행한다. 이벤트 순서·revision·제출 상태를 확인한 뒤 결과를 반영한다.

추적은 run·tool·command·checkpoint ID로 남긴다. 공개 상태와 내부 지시를 분리하고 비공개 사고 과정은 수집하지 않는다. 외부 추적에 원문을 기본 전송하지 않는다.

## 맡지 않는 범위

업무 SQL 변경, 시계·자동 제출 소유, 원본 사건의 유일 기록기, 직접 기업 인증, 시나리오 상세 작성, 역량 판정·채점, 리포트 워커 역할.

## 완료 기준

- Graph 설계와 코드의 노드·분기·반복이 대응하고 저장·재개 후 변경이 중복되지 않는다.
- 실제 두 MCP 서버에서 도구를 발견·호출하고 모델이 도구를 선택한 실행 증거가 남는다.
- 호출 한도·근거·판정 금지·컨텍스트 분리가 동작한다.
- 문서 승인/거절·프로세스 복구·빈 설정·Gateway 종료 통지를 처리한다.
