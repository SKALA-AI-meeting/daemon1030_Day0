# report-worker — 종료 기록 기반 분석·리포트 구현 범위

기준: [루트 설계](../../AGENT.md) 4.2·7·10장, [서비스 공통](../AGENT.md).

## 역할과 기술

Python 워커가 RabbitMQ 작업을 받아 확정된 응시 스냅샷을 읽고 PostgreSQL에 분석·작업 상태·리포트를 저장한다. 2026-10-20 후속 사용자 승인에 따라 gpt-4o-mini로 시나리오별 결과물 검토·역량별 간략 평가를 생성한다. 관찰 사실과 AI 해석은 분리하고 점수·채용 판정·성격 단정은 생성하지 않는다.

## 처리 흐름

작업 수신 → 종료 스냅샷·프로젝트 선택 역량·고정 규칙 조회 → 규칙 계산 → 원문 근거 연결 → 문장 정리 → 인용·금지 표현 검증 → 리포트 저장 → ACK.

## 구현할 기능

- 작업의 session_id·snapshot_id·report_version·프로젝트 소속을 검증한다. 전체 대화는 큐 payload에 넣지 않는다.
- 선택한 3~6개 역량만 결과 배열로 만들고, 관련 행동 없음·관찰 기회 없음·시스템 실패를 구분한다.
- C06 미선택이면 AI 활용 평가를 별도 추가하지 않는다. AI 미사용은 부정적 판단 없이 표시한다.
- 원본 메시지·문서 버전·태스크·어시스턴트 요청/응답과 근거 ID를 연결한다. 원본·시각·인용·세션 일치를 확인한다.
- 결정적 지표는 동일 스냅샷·규칙 버전에서 동일해야 한다. 구현 코드는 이 폴더, 역량 정의·규칙 메타데이터는 competencies, 규칙 형식은 contracts에서 관리한다.
- 키워드·유사도만으로 성격·갈등 태도·검증 여부를 확정하지 않는다. 사용자가 승인한 v2의 내용 검토는 버전이 고정된 기준·원문 근거 안에서 수행하고 한계를 표시한다.
- 문서 수정 사용과 결과 검증을 구분한다. 출처를 확인하지 못하면 활용 방식 확인 불가로 표시한다.
- 점수·순위·합격/불합격·성향 단정 문구를 금지한다. 근거 없는 문장·인용은 실패 처리 또는 검증된 중립 형식으로 제한한다.
- 관찰 규칙이 없는 개발 실행은 not_configured로 마무리한다. 가상 관찰을 생성하지 않는다.

## 큐·데이터 경계

- Gateway가 종료·Outbox·작업 등록을 소유한다. 워커가 실행 중 세션의 상태·문서·사건을 변경하지 않는다.
- `(session_id, snapshot_id, report_version)` 등 합의된 유일 키와 처리 선점으로 중복 소비를 제어한다.
- 결과·작업 상태 저장 이후 ACK한다. 장애 뒤 같은 작업을 받아도 완료 결과를 중복 생성하지 않는다.
- 재시도 횟수·간격은 infra·contracts와 일치시키고 상한 초과 시 DLQ·실패 사유를 남긴다.
- 확정 업무 기록은 읽기만 하고 분석·리포트·작업 상태 영역만 쓴다. ORM·DB 권한은 migrations와 협의한다.

## 맡지 않는 범위

원본 행동 수집, 사용자 인증·API, 사건 연출, Graph 진행, 시나리오 상세·새 관찰 기준의 임의 작성, 기업 통보·개인 피드백 제품 기능.

## 완료 기준

- fixture 스냅샷에서 선택 역량만 표시하고 원본 인용 검증을 통과한다.
- 규칙 없음·관찰 없음·AI 미사용·근거 불일치를 구분한다.
- 같은 스냅샷 재실행 지표가 같고 워커 재시작·중복 전달에도 리포트가 하나다.
- 생성 실패→재시도→DLQ, 저장 후 ACK, 제출 완료와 분석 실패의 분리를 검증한다.

## AI 검토 v2

- 제출 스냅샷의 review 기준·공개 자료·최종 지원자 문서를 읽는다. 기존 스냅샷이나 시나리오 발행본을 수정하지 않는다.
- 최종 제출물의 작성 유무는 코드로 확인하고, 기준 충족 여부와 보완점은 AI 해석으로 구분한다.
- 선택 역량과 기준 ID 집합, 모든 인용의 원문 일치, 결과물의 해당 최종 문서 참조를 검증한다.
- 자료·사건 미제공, 작성 없음, 근거 부족, 모델 실패를 서로 구분한다. 실패 시 활동 기록은 유지하고 AI 평가를 만들지 않는다.
- 모델 호출 동안 DB 트랜잭션을 열어두지 않는다. PostgreSQL 세션 advisory lock으로 중복 작업을 직렬화한다.
- 동일 스냅샷의 결정적 사실은 동일하지만 AI 해석의 문구는 재생성 시 달라질 수 있다. 완료 작업의 중복 전달은 저장된 결과를 반환한다.
