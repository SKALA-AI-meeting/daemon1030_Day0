# gateway — 업무 API·인증·세션 진행 구현 범위

기준: [루트 설계](../../AGENT.md) 1.3·3·4·8·9장, [서비스 공통](../AGENT.md).

## 역할과 기술

Python·FastAPI로 브라우저의 유일한 업무 진입점을 구현한다. PostgreSQL에 저장되는 계정·기업·프로젝트·초대·세션·원본 기록과 승인 레코드의 업무 규칙을 소유한다.

## 구현할 기능

1. 기업 관리자·개인 계정의 인증, 기업 소속·역할 확인, 로그아웃·만료 처리. 초대 링크는 개인 로그인을 대체하지 않는다.
2. 역량 6개 조회와 중복 없는 3~6개 선택 검증, 선택 전체를 지원하는 발행 시나리오 조회, 프로젝트 생성·버전 고정.
3. 프로젝트별 초대·만료·계정 귀속·본인 수락, 개인 평가 목록, 기업의 지원자 상태 조회.
4. 안내문·동의문 버전 기록, 시작·제출 중복 처리, 종료 후 쓰기 차단.
5. 메시지·문서 자동 저장·문서 버전·태스크·분업안·어시스턴트 요청/응답 원본 저장.
6. Runtime: 설정 로딩, 서버 시계, 사건 선점·중복 방지, 공개 자료 상태, 자동 제출. 빈 사건 목록 지원.
7. 메시지는 먼저 저장하고 Agent에 처리를 요청한다. Agent 결과에도 역할·채널·세션 상태를 검사한다.
8. WebSocket으로 허용된 사건·업무 변경·생성 상태 전달, 저장 사건 순서·재조회 제공.
9. 최종 문서·근거 범위의 스냅샷과 세션 종료·리포트 Outbox를 같은 트랜잭션으로 저장한다.
10. Outbox 전달기가 RabbitMQ에 작업을 전달하고 확인 결과를 관리한다. 리포트 실패가 제출을 되돌리지 않게 한다.
11. 문서 원문·승인 대상 해시·관리자 결정 저장, Agent 문서 관리 실행 시작·승인/거절 재개 API.
12. 기업에 권한 있는 리포트·작업 상태를 제공한다. 실제 분석은 워커가 담당한다.

## API·연결

- 외부: `/auth/*`, `/competencies`, `/scenario-options`, `/projects`, 프로젝트 초대·지원자, `/me/assessments`, 동의·시작·업무·제출·리포트.
- 내부: business-mcp의 업무 조회·변경, rag-mcp의 원문·승인·공개 버전 검증, Agent의 실행 맥락·응답 저장.
- 입력·출력·오류·사건은 [contracts](../../contracts/AGENT.md)에서 합의한다. 경로별 세부 메서드·오류 응답은 그곳에 단일 정의한다.
- Agent 호출·MCP 요청을 처리할 때 DB 트랜잭션을 장시간 열린 채 모델 응답을 기다리지 않는다.

## 데이터·동시성 책임

- 기업·계정·세션의 관계를 서버에서 검증한다. 다른 기업 ID의 존재 여부도 노출하지 않는다.
- 프로젝트의 선택 역량·시나리오·자료·관찰 규칙은 생성 시 고정한다. 지원 역량이 미정인 시나리오는 일반 평가로 발행하지 않는다.
- 원본 사건은 AI 도구 호출과 독립적으로 남긴다. `(session_id, scenario_event_id)` 등 유일 제약은 [migrations](../../migrations/AGENT.md)와 맞춘다.
- 문서·태스크 변경은 revision과 멱등 키를 확인한다. 제출·자동 저장·늦은 Agent 응답 경합을 처리한다.
- 분업 수락·최대 조정 정책, 도구별 담당·현재 사건 허용 범위를 검사한다.
- 연결 종료 감지 시 일시정지·재접속 재개, 언제든 최종 제출은 확정된 정책이다. 최대 재개 기한·보관 기간은 미정으로 유지한다.

## 맡지 않는 범위

Graph·모델 판단·MCP 프로토콜 서버·벡터 검색·역량 분석·LLM 리포트 요약은 구현하지 않는다. 다른 서비스에 넘기더라도 업무 권한의 최종 검사 책임은 유지한다.

## 완료 기준

- 기업·개인 정상 흐름과 타 기업·타 개인 접근 거절이 API에서 검증된다.
- 2개·중복·미등록·7개 이상 역량, 지원 부족·미발행 시나리오를 거절한다.
- 빈 설정으로 개발용 응시·기록·제출이 가능하되 실제 평가와 구분된다.
- 사건·제출·Outbox 중복과 프로세스 재시작·응답 유실을 처리한다.
- 도구 호출·실시간 이벤트·리포트 스냅샷을 원본과 연결할 수 있다.
