# 구현 현황

기준일: 2026-10-20. 시나리오 3종 v1의 상세·시간별 직원 개입을 구현했습니다. [운영 명세](scenarios-v1.md)를 참고하세요.

## 실행 가능한 공통 흐름

- Vue 기업·개인 가입·로그인·로그아웃, 기업/개인 접근 분리.
- 6개 역량 조회·3~6개 선택 검증·시나리오 전체 지원 조건·프로젝트 버전 고정.
- 프로젝트별 초대, 개인 계정 귀속·수락·평가 목록·동의·시작.
- 과제 문서 자동 저장·revision 충돌·태스크 상태 변경·채널 메시지·원본 사건 기록.
- WebSocket 시간·사건 전달, 단절 감지 일시정지·재접속, 언제든 제출·완료 표시.
- PostgreSQL 마이그레이션, 제출 스냅샷·Outbox, RabbitMQ 전달·워커 소비·분석 미설정 표시.
- 실제 business-mcp·rag-mcp 연결, 도구 탐색·업무 조회/변경·권한 거절·벡터 검색.
- Agent의 모델/도구 반복·한도·역할 분리·영속 체크포인트, 사내 문서 관리자 승인 interrupt/재개.
- 서버 환경에 모델 키가 있으면 실제 gpt-4o-mini 동료·어시스턴트 응답. 없으면 저장을 유지하고 연결 불가 안내.
- 분업 제안·지원자 수락/조정 결정·담당 반영 경로. 초기안 이후 최대 3회 조정 시 마지막 안을 적용하는 서버 경계.

## 완료와 구분할 사항

- S01-v1~S03-v1은 각 5개 역량을 지원합니다. 6개 전체를 지원하는 버전은 없습니다. 발행은 MVP 설정의 제공 상태이며 인재 평가 타당도 검증을 뜻하지 않습니다.
- 120분 누적 시계와 9회 고정 직원 메시지, 단계별 자료 공개·직원 정보 갱신을 연결했습니다. 팀장·협업 동료를 선택해 대화할 수 있습니다.
- v1은 상황·활동 근거를 연결합니다. v2는 시나리오별 결과물 기준 6개와 선택 역량별 AI 평가를 추가하며 [검토 명세](report-review.md)를 따릅니다.
- 관찰 규칙이 없는 실행에서 분석 결과를 생성하지 않습니다. 관찰 사실과 AI 해석을 구분하며 성격·채용 판정은 생성하지 않습니다.
- 기본 API/Graph 테스트는 모델 대역이며, 모델 API를 매번 호출하지 않습니다. 브라우저에서 실제 모델 응답은 별도로 확인했습니다.
- 개발 임베딩은 합성 검색 검증용입니다. 실제 한국어 모델 선정·성능 검증은 남아 있습니다.
- Agent 체크포인트는 현재 별도 SQLite 파일입니다. PostgreSQL 체크포인트 전환과 DB 서비스별 최소 권한 역할·복합 관계 제약 강화는 후속 항목입니다.
- 기본 사용자 모델은 기업 계정당 하나의 기업 범위를 사용합니다. 여러 기업 관리자 초대·조직 멤버십 관리 화면은 구현하지 않았습니다.
- 문서·AI 요청 출처 연결은 앱 안에서 확인 가능한 범위만 기록합니다. 외부 복사·수동 재작성 출처를 완전히 추적하지 않습니다.
- 자동 제출·저장 경합·연결 중단 정책과 핵심 접근 검사를 테스트합니다. 전면적인 부하·보안 감사나 심리측정 타당도 검증을 완료했다는 의미는 아닙니다.
- 실제 시나리오 규칙에 연결한 규칙 실행기 전용 record_observation 경로, 상세 디브리핑 양식·원문 이동·무응답 알림·보관/삭제 정책은 후속 구현·결정 항목입니다.

## 기업·개인 UI 개편 (2026-10-20)

- 목업의 블루·화이트 색상과 화면 구성을 실제 Vue 페이지에 적용. 기존 가상 오피스는 Slack 색상 유지.
- `/projects/new`: 기본 정보 → 역량 선택 → 서버의 지원 시나리오 조회·확인.
- 기업 프로젝트 카드의 초대·완료·준비 리포트 건수는 Gateway가 기업 소유 프로젝트에 한해 집계한다. 0건과 분석 대기를 구분한다.
- 프로젝트 상세: 실제 응시 현황, 검색·상태 필터, 초대 링크 대화상자·복사.
- `/projects/:id/reports/:sessionId`: 지원자 목록과 리포트 분리. AI 종합 의견·결과물 검토·역량별 의견, 원문 근거와 활동 기록 펼치기. 기존 v1·분석 미설정·분석 실패 상태도 유지.
- 개인 평가: 진행/완료 목록 분리, 설정 기반 제한 시간, 응시 전 사용법·시간·제출·기록 동의 안내.
- 프로젝트·시나리오 옵션·개인 평가·세션 응답에 `duration_seconds`를 제공하며, 프로젝트 목록의 `counts`는 `invited`, `running`, `submitted`, `reports_ready`다. DB 스키마·응시 및 분석 정책은 변경하지 않았다.
- UI 확인: 기존 합성 계정에서 프로젝트 생성 단계 전환·역량 3개 선택·실제 시나리오 조회, 지원자 필터·초대 창·리포트 경로 이동, 개인 평가의 진행/완료 분리를 확인.
