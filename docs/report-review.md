## 생성과 경계

- 제출 시 최종 지원자 문서, 원본 사건, 선택 역량, 검토 기준, 종료 시점까지 공개된 자료를 스냅샷에 고정합니다. 미래 자료·직원 전용 지침은 평가 입력에 포함하지 않습니다.
- 결정적 활동 연결 이후 gpt-4o-mini가 strict JSON Schema 형식으로 반환하며, 근거 번호도 허용 목록으로 제한합니다. 모델·스키마·기준 버전·기준 해시를 저장합니다.

- 입력 문서와 메시지의 지시문은 데이터로 취급합니다. 점수·순위·채용 판정·성격 단정을 금지합니다. 인용 검증만으로 판단의 의미적 정확성이 보장되지는 않습니다.
- 관련 변경 상황 미제공, 제출 내용 없음, 연결 행동 근거 부족, AI 생성/검증 실패를 구분합니다. 결과를 추정해서 채우지 않습니다.

- 각 역량은 그 상황·연결된 행동·관련 문서 이력으로 별도 검토합니다. 결과물의 각 기준은 해당 최종 문서·참고 자료만으로 검토하고, 종합 의견은 이 결과들을 모아 생성합니다. 동시 검토 요청은 최대 2개입니다.

- 이전 버전 응시에는 기준이 없으므로 새 AI 평가를 소급 생성하지 않습니다. 새 버전의 별도 샘플 응시를 생성해 검증합니다.
