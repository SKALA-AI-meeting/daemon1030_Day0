# scenarios — 시나리오 버전·설정 데이터 범위

기준: 루트 AGENT.md와 docs/scenarios-v1.md. 2026-10-20 사용자가 상세 구현을 승인했으므로 이전 보류 지침을 대체합니다.

- S01 신규 기능 개선안 기획, S02 서비스 장애·고객 불만 대응, S03 출시 준비·팀 업무 조율을 구현합니다.
- `catalog.json`은 과거 이름·초안 참조이며 `versions/`의 버전 ID가 실제 발행 선택지입니다. 기존 프로젝트의 스냅샷을 수정하지 않습니다.
- 과제·역할·자료·제출물·누적 시간별 직원 메시지·사건 후 역할 정보·관찰 규칙을 contracts/scenario 형식으로 관리합니다.
- 공통 시간·인가·공개 자료 처리는 Gateway, 응답 생성은 Agent, 문서 검색은 rag-mcp, 근거 연결은 워커가 담당합니다.
- 지원 역량은 관찰 기회·규칙이 연결된 항목만 등록합니다. 모든 시나리오가 6개를 지원한다고 가정하지 않습니다.
- 직원 정시 메시지는 모델 실패와 무관하게 전달하며, 미래 사건·규칙·비공개 자료는 지원자와 모델에게 미리 공개하지 않습니다.
- 발행 설정은 새 버전으로 변경합니다. 기존 버전을 덮어쓰는 seed는 구현하지 않습니다.
- 합성 개발 fixture는 계속 tests/fixtures에 격리합니다. 점수·순위·합격 판정·심리측정 타당성을 주장하지 않습니다.

완료 기준: 설정 참조 검증, 시간 순서·일시정지·중복 방지, 자료 공개 경계, 사건 이후 역할 정보, 선택 역량별 원문 근거 연결을 테스트합니다.
